## 🚀 Geocross-Hospital v1.0 - Built & Deployed on AWS

Hospital booking system built with Node.js + Express, fully Dockerized and deployed on AWS EC2.

Tech: EC2 | Docker | Linux | Node.js | Express | Git

What I solved:
- Deployed Node app on EC2 Ubuntu via SSH
- Built Dockerfile and ran `docker run -d -p 3000:3000`
- Fixed real DevOps issues: EACCES permission, port conflict, container crash
- Second service Geocross-app on port 3001

Currently stopped to manage AWS free tier credits. Code and deployment steps documented in repo.
